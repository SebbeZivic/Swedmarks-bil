# Swedmarks Bil 🚗

En modernt bilförsäljningsplattform byggd med React + Node.js

## Features
- Bilkatalog med filter och sök
- Admin-panel för att hantera bilar
- Bildgalleri med zoom
- Favoriter (sparas lokalt)
- Användarautentisering

## Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
